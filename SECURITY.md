# Security / 安全问题

Please report vulnerabilities privately using
[Report a vulnerability](https://github.com/jonathanhu237/temvia/security/advisories/new).
Do not post exploit details, credentials, or private application data in public Issues.
Include the generator version, affected generated code, impact and minimal reproduction.

安全漏洞请通过上述 GitHub 私密报告入口提交，不要在公开 Issue 中发布漏洞利用细节、
凭据或应用私有数据。请说明生成器版本、受影响代码、影响和最小复现。

Maintenance is best effort. There is no guaranteed response time or long-term
support for older versions. Generated applications must apply relevant fixes
manually; updating the generator does not update an existing application.

项目尽力维护，不承诺固定响应时间或旧版本长期支持。生成项目需自行合并适用修复，
升级生成器不会自动更新已有应用。
