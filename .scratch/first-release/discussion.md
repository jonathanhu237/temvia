- Q8：生成器和模板自有代码采用 MIT，允许商业及闭源使用，保留相应版权、许可和第三方声明。
- Q9：文档明确目前仅在 macOS 下测试过完整首次使用流程；Linux、WSL2 暂列未经完整验证的环境。既有 Centaurus 组件和浏览器测试不等于 Linux 从零安装验收。

- Q11：通过 GitHub Actions 发布，由维护者明确触发；普通推送不自动发布新版。账号和权限配置在实施阶段核实。

- Q13：认可下列首版发布门槛，不新增功能或发布展示网站。
