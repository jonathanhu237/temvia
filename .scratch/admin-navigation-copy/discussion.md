# 后台导航与在线用户文案调整

Status: resolved
Stage: discussion-complete
Implementation authorization: not-requested

## 已明确的反馈

- “踢下线”是需求讨论中的口语表达，不应直接作为产品界面的操作、权限或历史记录文案。已记入领域词汇的避免用语。
- 在线用户页面不应添加现有的说明性副标题。
- 在线用户和操作历史归入“系统监控”一级菜单。

## 当前事实

- 一级菜单为：首页、用户与权限、操作历史、系统设置。
- 在线用户目前属于用户与权限；该组还包含用户、邀请、角色。
- 在线用户页面有主标题、说明性副标题和卡片内重复标题。
- 本人退出菜单使用“退出登录”；管理操作目前使用“踢下线”。
- 现有约定要求系统设置放最后；菜单和数据访问均由各自权限控制。

## 第一轮设计树

1. Q1 已确认：管理操作统一使用“强制退出 / Force sign out”，覆盖按钮、权限、确认、反馈及操作历史；确认框说明退出所有设备、可以重新登录。
2. Q2 已确认：一级菜单叫“系统监控”，子菜单依次为在线用户、操作历史；用户与权限保留用户、邀请、角色；系统设置继续放最后。
3. Q3 已确认：全后台只保留一个页面主标题，不添加说明性副标题或重复标题。在线用户当前的副标题和卡片内重复标题均应删除。

## 讨论结论

用户已明确回复“Q1 OK / Q2 OK / Q3 OK”，本轮讨论完成，无待决设计问题。正式用语记入 CONTEXT.md，长期界面规范记入 AGENTS.md。本轮决策取代旧在线用户规格中关于导航位置及“踢下线”产品文案的安排。

## 实施边界

本轮按 grill-with-docs 讨论并整理词汇和决策。讨论完成后明确告知用户，等待用户另行明确请求实施。
